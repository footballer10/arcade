# Arcade Prototypes

Three browser game prototypes for testing: Arena Royale (`/arena`), Downhill Rush (`/downhill`), Mini-Golf Battle (`/golf`).

Run locally: `python3 -m http.server 8000` from this folder, then open http://localhost:8000

Each game lives only in its own folder. Do not edit other games' folders or the root index.html from a game's session.
