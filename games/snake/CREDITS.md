# Snake Royale — credits

Everything in this game is made in code; there are no downloaded asset files.

- Graphics: procedural (Three.js geometry, a custom floor shader, canvas-drawn glow sprites). `thumb.svg` drawn by hand.
- Sound: synthesized at runtime with the Web Audio API through the hub's shared audio engine.
- Libraries: Three.js 0.160.0 (MIT) from the hub's import map.
