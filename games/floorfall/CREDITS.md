# Floor Is Falling — credits

Everything in this game is made in code; there are no downloaded asset files.

- Graphics: procedural Three.js geometry (instanced hexagon tiles, tumbling debris, the glowing void), a gradient sky
  shader and canvas-drawn glow textures. Players use the hub's shared avatar and hats. `thumb.svg` drawn by hand.
- Sound and music: synthesized at runtime with the Web Audio API through the hub's shared audio engine
  (master / music / sfx buses).
- Libraries: Three.js 0.160.0 (MIT) from the hub's import map.
